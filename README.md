# tfm-fintech-easymoney
# easyMoney – Final Data Science Project

## Objetivo
Aumentar la rentabilidad de la base de clientes actual mediante analítica y modelos de Data Science, reduciendo la dependencia de captación intensiva de nuevos clientes.

## Entregables (alto nivel)
- Nuevo BI self-service (KPIs clave y visualizaciones para el equipo)
- Segmentación de clientes (7–8 grupos) + perfilado para marketing
- Recomendación de producto para campaña (10.000 e-mails) + estimación de respuesta/ROI
- Personalización de creatividades (4–5 mensajes según perfil) + propuesta de medición
- Seguimiento: KPIs de campaña y KPIs de estrategia + metodología de mejora continua
- Presentación final para stakeholders (insights, recomendaciones y próximos pasos)

## Estructura del repositorio
- `data/`  
  - `raw data/` (NO se sube a Git)  
  - `processed/` (NO se sube a Git)
- `notebooks/` – exploración, EDA y prototipos
- `src/` – código reutilizable (features, preparación, modelos)
- `docs/` – documentación (KPIs, diccionario de datos, decisiones)
- `reports/` – resultados, figuras y resúmenes
- `outputs/` – ficheros finales (p. ej., etiquetas/segmentos)

## Reglas rápidas
- No subir datos a Git (ver `.gitignore`)
- Trabajar por ramas: `feature/...` y PR antes de merge a `main`
- Nombrado sugerido de notebooks: `01_...`, `02_...`, etc.
- Validar resultados clave con el supervisor antes de entregar/presentar

## Cómo empezar
1. Clona el repositorio
2. Revisa `docs/KICKOFF_CHECKLIST.md` (cuando esté creado)
3. Coloca los datos en `data/raw data/`
4. Empieza con el notebook `notebooks/01_eda_overview.ipynb` (por crear)
